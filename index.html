Features
Everything you need to
create great presentations
A fully-featured desktop app built with Java Swing and Apache POI.
✦
AI Slide Generation
Describe your presentation in plain English and get a complete, structured deck generated in seconds using Groq's Llama 3.3 model.
✎
AI-Powered Editing
Select any slide and ask the AI to rewrite, improve, or expand it. Apply changes to one slide or your entire presentation at once.
⬇
Real .pptx Export
Export your presentation as a proper PowerPoint file using Apache POI. Open it in Microsoft PowerPoint or Google Slides immediately.
🎨
8 Beautiful Themes
Choose from Professional Dark, Clean Light, Corporate Blue, Emerald, Crimson Bold, and more. Live preview updates instantly.
✍
Typography Control
Pick from 10 font families and adjust body text size. All changes reflect in the slide preview and the exported file.

Speaker Notes
AI automatically generates speaker notes for every slide, saved inside the exported .pptx file for use during presentations.
